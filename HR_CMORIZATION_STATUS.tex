\sect{Where we are}
The pipeline turns one model year into a complete, CMIP7-structured data set in under four hours. Against the
QC checker DKRZ will publish with (\code{cc-plugin-wcrp} coordinate checks, PR \#81), the latest test year has
\textbf{no HIGH findings from the CMIP7 plugin on any of its 529 files}. What remains is upstream work in the
checkers and tables, a review of flagged values, and running the 196 years.

\vspace{2pt}
Across the DKRZ review rounds (Martin Schupfner), every finding in our files has been fixed and re-measured.
Along the way we reported or fixed more than a dozen issues upstream in \code{compliance-checker}, \code{cc-plugin-wcrp},
the WCRP universe and the data request, and registered our grids in the Essential Model Documentation, including
the zonal-band grid \code{g239}.

\sect{Built and working}
\begin{itemize}
\item Year-by-year submission as SLURM shard arrays (17 tiers, 59 tasks), with QC running inside every job.
\item Unstructured FESOM output with CMIP7 grid variables and cell vertices, one coordinate set per grid.
\item Climatologies and monthly means of daily extremes as CF climatologies; decadal means written from
      ten years of input by year-by-year jobs, verified against the raw model output.
\item Value checks on every file against literature ranges: 307 of 529 pass, 169 sit slightly outside.
\end{itemize}

\sect{Still to do before publication}
\begin{itemize}
\item \textbf{Values:} understand the 53 files outside plausible ranges. 49 have been flagged since August, some
      are ranges set too tight (ch4 and n2o are confirmed false alarms); sea-ice and ocean transport cases need a look.
\item \textbf{Checkers:} the release with the coordinate checks and the registry fix is expected by the end of
      September. Until then 42 files fail TIME001 in the released version.
\item \textbf{Open details:} two conventions for decadal means are with DKRZ; how the running climatology file is
      named across years needs checking; five 6-hourly variables on seven pressure levels cannot be produced for HR.
\end{itemize}

\sect{Scale of the production run}
196 years (1850--2045): about \textbf{98\,600 files and 92\,TB}, roughly 6\,500 node-hours at the current rate.
Write permission on the DKRZ ESGF data node is in place.
